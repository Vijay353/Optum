# Workbook schema reference — EB-WB-1.0

Generated by `npm run template` from `src/data/workbookSchema.ts`. Do not edit by hand.

Limits: 2 MB per file, 2000 rows per sheet, 30 columns per sheet. Formats: .xlsx (preferred) or one `<entity>.csv` per entity (merge mode only).

## patients

Synthetic patients. Only an identifier and age band — no names, dates of birth or addresses.  
Owner: Mock EHR · Primary key: `id`

| Column | Type | Required | Editable | Allowed | Description |
|---|---|---|---|---|---|
| `id` | string | yes | yes |  | Synthetic patient id SYN-PAT-#### (real identifiers are rejected) |
| `ageBand` | string | yes | yes | 0-17, 18-34, 35-54, 55-64, 65+ | Age band |

## prior_auth_drafts

Prior-authorization drafts. Updating a draft requires a higher version (optimistic concurrency).  
Owner: Mock EHR · Primary key: `id`

| Column | Type | Required | Editable | Allowed | Description |
|---|---|---|---|---|---|
| `id` | string | yes | yes |  | PA-DRAFT-##### |
| `version` | int | yes | yes |  | Positive integer revision; must increase on every content change |
| `serviceRequestId` | string | yes | yes |  | FK → service_requests.id |
| `patientId` | string | yes | yes |  | Must match the service request |
| `coverageId` | string | yes | yes |  | Must match the service request |
| `policyVersion` | string | yes | yes |  | FK → policy_requirements.policyVersion |
| `businessStatus` | string | yes | yes | DRAFT_INCOMPLETE | System-managed workflow state; imports may only use DRAFT_INCOMPLETE |
| `createdAt` | datetime | yes | yes |  | ISO 8601 with timezone, e.g. 2026-10-16T14:00:00Z |
| `updatedAt` | datetime | yes | yes |  | ISO 8601 with timezone; not before createdAt |

## Invalid-data examples

| File | What is wrong |
|---|---|
| `invalid/missing-sheet.xlsx` | coverage sheet removed (fails in replace mode) |
| `invalid/wrong-types.xlsx` | non-integer version, non-boolean attributed |
| `invalid/duplicate-ids.xlsx` | duplicate patient primary key |
| `invalid/orphan-reference.xlsx` | coverage points at a patient that does not exist (cascades to dependents) |
| `invalid/invalid-status.xlsx` | system-managed status supplied by import |
| `invalid/formula-cell.xlsx` | formula cell (never evaluated; rejected) |
| `invalid/stale-revision.xlsx` | draft PA-DRAFT-99412 at v1 while the simulator holds v3 |
| `invalid/real-identifier.xlsx` | SSN-like text and a non-synthetic patient id |
